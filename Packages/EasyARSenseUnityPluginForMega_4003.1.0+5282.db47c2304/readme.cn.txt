EasyAR Sense Unity Plugin for Mega
使用 UPM (https://docs.unity3d.com/Manual/upm-ui.html) 导入package。
    com.easyar.sense：EasyAR Sense Unity Plugin主体。
    com.easyar.mega：EasyAR Mega Support。
    com.easyar.mega.studio: EasyAR Mega Studio。面向非Unity开发。
请阅读EasyAR网站上的文档来了解应该如何使用：https://help.easyar.cn/EasyAR%20Mega/
