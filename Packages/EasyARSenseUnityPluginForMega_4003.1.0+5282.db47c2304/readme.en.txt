EasyAR Sense Unity Plugin for Mega
Use UPM (https://docs.unity3d.com/Manual/upm-ui.html) to import packages.
    com.easyar.sense: EasyAR Sense Unity Plugin main package.
    com.easyar.mega: EasyAR Mega Support.
    com.easyar.mega.studio: EasyAR Mega Studio. Not for Unity developers.
Please read the documents on EasyAR website for how to use, https://help.easyar.com/EasyAR%20Mega/
